# Comandos Dev — Anki (Git + primer backend)

Deck práctico con los **comandos y fragmentos de código** de la sesión en que se
creó el primer backend (`miniproyectos-dev/registro-estudios`).

- **Front:** el comando o el fragmento de código.
- **Back:** qué hace · qué resuelve · por qué.

Cubre, por secciones: GitHub (`gh`), terminal (`mkdir`, `cd`, `ls`, `cat`, `rm`, `mv`…),
git (`add`/`commit`/`push`, `remote`, `status`), entorno (`venv`, `pip`, `which`, `py_compile`),
editor (`nano`), correr FastAPI (`uvicorn`, `/docs`, `Ctrl+C`) y cada línea del `main.py`
de la Capa 1.

Deck en Anki: **Basicos Dev::Comandos (Git + primer backend)** — 50 tarjetas.

## Regenerar
```bash
../../.venv/bin/python build_comandos.py
```
GUID estable por posición: corregir un texto y reimportar **actualiza** la carta, no la duplica.
El `.apkg` queda en `output/` para importar en Anki.
