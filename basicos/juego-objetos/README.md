# Recrear la API — dojo de clases, objetos y métodos

Practica de tecleo estilo "reconstruir el stack": el juego te da una
situacion/tematica y tu tecleas el codigo (clase, esquema, objeto, metodo o
endpoint) en el archivo que le toca (models.py, main.py, database.py, crear_db.py).

- 18 escenarios, filtrables por archivo.
- Tab indenta; Enter mantiene la indentacion (y agrega tras los ":").
- Boton de pista y de ver/ocultar solucion.
- "Comparar" es tolerante a espacios: valida estructura e indentacion.

Un solo archivo (index.html). Se abre directo, sin instalar nada.
